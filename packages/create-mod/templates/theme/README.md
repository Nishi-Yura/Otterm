# __NAME__

An otterm color theme (`__ID__`). The colors are in `theme.toml`.

## Try it

While you edit, link this folder into otterm from the mod's folder:

```sh
otterm mod install --link .
```

Then select the theme in otterm's theme settings. Each key under `[theme.ui]` is exposed to mods as `--ot-<key>`, so every mod follows your colors.
