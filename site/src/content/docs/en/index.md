## Where to start

- If you have never used a terminal, start with [Getting started](/en/guide/getting-started/).
- To change settings or keys, read [Settings](/en/guide/settings/) and [Key bindings](/en/guide/keybindings/).
- To write a mod, start with the [mod author guide](/en/mods/). The types are in the [API reference](/en/api/).

> v1.0 is released for Windows first. macOS and Linux builds follow in 1.0.x.
