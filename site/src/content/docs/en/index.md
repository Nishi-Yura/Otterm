## Where to start

- **New to terminals**: start with [Getting started](/en/guide/getting-started/). Pebble, the otter, is there to guide you.
- **Changing settings or keys**: read [Settings](/en/guide/settings/) and [Key bindings](/en/guide/keybindings/).
- **Writing a mod**: start with the [Mod author guide](/en/mods/). The types are in the [API reference](/en/api/).

> v1.0 is released for Windows first. macOS and Linux builds follow in 1.0.x.
