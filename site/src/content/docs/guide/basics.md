ここでは Windows と Linux の既定キーを示します。macOS では `Ctrl+Shift` の代わりに `Cmd` を使います（一部は別のキーです。[キーバインド](/guide/keybindings/) を参照）。

## タブ

| 操作 | キー |
| --- | --- |
| 新しいタブ（既定のシェル） | `Ctrl+Shift+T` |
| プロファイルを選んで開く | `Ctrl+Shift+N` |
| タブを閉じる | `Ctrl+Shift+W` |
| 次のタブ／前のタブ | `Ctrl+Tab` ／ `Ctrl+Shift+Tab` |
| 番号でタブを選ぶ | `Ctrl+1` 〜 `Ctrl+9` |

タブは、ドラッグで並べ替えたり、別のウィンドウへ移したりできます。タブ名は、待機中はフォルダ名、コマンドの実行中は「コマンド名 · フォルダ名」になります。

## シェルは閉じるまで動き続ける

シェルは otterm のウィンドウとは別のプロセスで動いています。ウィンドウが落ちても、更新や設定の反映で otterm が再起動しても、シェルは止まらず、スクロールバックもそのまま残ります。次に開いたウィンドウが同じタブを開き直します。

普通にウィンドウを閉じたときは、シェルも終わります。閉じても残しておきたいときは、設定で `general.keep_sessions = "always"` にします。今までどおりウィンドウの中で動かすなら `"never"` です（再起動が必要）。

## ペイン（分割）

| 操作 | キー |
| --- | --- |
| 縦に分割 | `Ctrl+Shift+D` |
| 横に分割 | `Ctrl+Shift+E` |
| ペイン間の移動 | `Alt+矢印` |
| サイズを変える | `Alt+Shift+矢印`、またはドラッグ |
| 最大化のオン／オフ | `Ctrl+Shift+Z` |
| ペインを閉じる | `Ctrl+Shift+Q` |

新しいペインは、分割元と同じフォルダで開きます。

## ブロック

otterm は、プロンプト、コマンド、出力、終了コードをひとまとまり（ブロック）として扱います。

- 左端の細い線で区切りを示します。成功は無色、失敗は赤、実行中は青で表示されます。
- `Ctrl+↑` と `Ctrl+↓` で前後のブロックへ移動します。
- `Ctrl+Shift+[` で直前のブロックの出力を折りたたみます。長い出力は、200 行を超えると自動で中央が折りたたまれます。
- ブロックを右クリックすると、「もう一度実行」「コマンドをコピー」「出力を保存」などを選べます。共有する形式は Markdown が既定です。

ブロック機能は、シェル統合が有効なときに働きます。詳しくは [シェル統合](/guide/shell-integration/) を読んでください。

## 検索

`Ctrl+Shift+F` で検索バーを開きます。プレーン、正規表現、大文字小文字の区別、単語一致を切り替えられます。ヒットの位置はスクロールバーに表示されます。

検索は、失敗したブロックだけ、特定のコマンドの出力だけ、といった絞り込みもできます。

## コピーと貼り付け

| 操作 | Windows | Linux | macOS |
| --- | --- | --- | --- |
| コピー | `Ctrl+C`（選択中のとき） | `Ctrl+Shift+C` | `Cmd+C` |
| 貼り付け | `Ctrl+V` | `Ctrl+Shift+V` | `Cmd+V` |

Windows では、選択していない `Ctrl+C` は通常どおり中断（SIGINT）になります。改行を含む貼り付けは、ガイドレベル 1 以上なら内容を表示して確認します。

右クリックで開くメニューには、コピー、貼り付け、AI に聞く、パスやリンクを開く、などが並びます。

## リンクとパス

URL やファイルパスは、`Ctrl+クリック`（macOS は `Cmd+クリック`）で開けます。ファイルは [設定](/guide/settings/) で決めた方法で開きます。

## コマンドパレット

`Ctrl+Shift+P` で開きます。タブ、ペイン、設定、テーマ、mod のコマンドを名前で探せます。

- そのまま打つとコマンドを探す
- `:` で行番号へ移動
- `?` で辞書を引く
- `@` でファイルを開く
- `#` でブロックを検索
- `!` に続けて打ったものを、シェルの入力欄に入れる（実行はしません。Enter はあなたが押します）

## フォントの大きさ

`Ctrl+=` で大きく、`Ctrl+-` で小さく、`Ctrl+0` で既定に戻ります。
