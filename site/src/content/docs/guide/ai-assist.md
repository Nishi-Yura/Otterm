AI 補助は、コツメに質問できる機能です。公式 mod の `otterm.ai-assist` として提供されています。インストールには含まれていますが、**既定ではオフ**です。

AI を使わなくても、辞書によるコマンドの説明、エラーの助言、危険ガードは動きます。

## 有効にする

オンボーディングの最後で「コツメに AI の力を貸しますか？」と聞かれます。既定は「あとで」です。有効にすると、プロバイダを選ぶ画面が開きます。

| プロバイダ | 必要なもの |
| --- | --- |
| `local`（Ollama など） | 手元のモデルとエンドポイント（既定は `http://localhost:11434`） |
| `claude` | 自分の API キー |
| `openai` | 自分の API キー |
| `gemini` | 自分の API キー |
| `openai-compatible` | エンドポイント URL と API キー |

API キーは設定ファイルには書かれず、OS のキーチェーンに保存されます。ローカルモデルへの接続確認は、プロバイダの画面を開いたときだけ行われます。

## できること

- **ことばでコマンドを作る**: 「コツメ、ポートを使っているプロセスを調べて」のように頼むと、コマンドを入力欄に入れます。
- **エラーの説明と修正案**: 失敗したコマンドの出力を読んで、原因と直し方を示します。
- **直前のコマンドを直す**: `fix` で、直前のコマンドを修正した案を出します。
- **出力について聞く**: 長い出力の要点や、特定の部分の意味を聞けます。

## 守っていること

- **実行はしません**。提案は入力欄に入るだけです。Enter を押すのはあなたです。
- 多段の作業も、1 ステップずつ確認しながら進みます。
- **送る前に見せます**。送信するテキストはプレビューで確認できます。
- パスワードやトークンに見えるものは、送る前に `[REDACTED]` に置き換えられます。
- 辞書で答えられるものは、AI を呼ばずに答えます。

## ログ

AI の利用ログは、既定で 30 日間残ります。`ai.log_retention_days` で変えられます。
