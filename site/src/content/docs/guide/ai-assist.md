AI 補助は、設定した AI に質問できる機能です。公式 mod の `otterm.ai-assist` として提供しています。インストールには含まれていますが、初期設定はオフです。AI を使わなくても、辞書によるコマンドの説明、エラーの助言、危険ガードは動きます。

## オンにする

オンボーディングの最後に「AI に質問する機能を使いますか？ 使うときは、送る内容を毎回見せます。」と聞かれます。既定は「あとで」です。オンにすると、プロバイダを選ぶ画面が開きます。

| プロバイダ | 必要なもの |
| --- | --- |
| `local`（Ollama など） | 手元のモデルとエンドポイント（既定は `http://localhost:11434`） |
| `claude` | 自分の API キー |
| `openai` | 自分の API キー |
| `gemini` | 自分の API キー |
| `openai-compatible` | エンドポイント URL と API キー |

API キーは設定ファイルには書かれず、OS のキーチェーンに保存されます。ローカルモデルへの接続確認は、プロバイダの画面を開いたときだけ行います。

## できること

自然な文章でやりたいことを書くと、コマンドの案が入力欄に入ります。たとえば「ポートを使っているプロセスを調べて」と書きます。失敗したコマンドについては、原因と直し方の案が出ます。`fix` を使うと、直前のコマンドを直した案が出ます。長い出力については、要点や特定の部分の意味を聞けます。

答えは「AI の回答」として表示します。コツメの発言ではなく、AI が返した文章です。コマンドの案の下には、実行する前に読むよう注意書きが付きます。

## 送る内容と、しないこと

- 実行はしません。案は入力欄に入るだけで、Enter を押すのはあなたです。
- 複数の手順が必要なときも、1 手順ずつ確認します。
- 送る前に、送る文字列をプレビューで見せます。
- パスワードやトークンに見える文字列は、送る前に `[REDACTED]` に置き換えます。
- 辞書で答えられるものは、AI を呼ばずに辞書で答えます。

## ログ

AI の利用ログは、既定で 30 日間残ります。`ai.log_retention_days` で変えられます。
