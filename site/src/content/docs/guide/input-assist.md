otterm は、入力中のコマンドを読んで説明を出したり、危険な操作の前で確認したりします。ただし、入力そのものはシェルが行います。Tab の補完や `Ctrl+R` の履歴、zsh-autosuggestions や fzf などのシェル側の拡張もそのまま使えます。

> ここで紹介する機能はどれも mod です（`otterm.cmd-explain`、`otterm.completion`、`otterm.danger-guard`、`otterm.error-hint`、`otterm.history-search`、`otterm.multiline-editor`、辞書の `otterm.dictionary-core`）。mod の画面（ステータスバーの「mod」）でオンにします。オフのあいだ、`Ctrl+R`、`Ctrl+Space`、`Shift+Enter` はシェルに届きます。

## ガイドレベル

ガイドレベルは、入力支援や案内の量をまとめて決める設定です。0 から 3 の 4 段階があり、設定画面とステータスバーからいつでも変えられます。

| レベル | 名前 | 動き |
| --- | --- | --- |
| 0 | オフ | 独自の表示はほぼありません。実行を止めるのは、特に危険な操作だけです。パネルは閉じています。 |
| 1 | ライト | 危険なときだけ説明と確認を出します。エラー助言は表示されます。 |
| 2 | スタンダード（既定） | 入力中のコマンドの説明を常に出します。左のファイルツリーを開きます。 |
| 3 | フル | レベル 2 に加えて、画面の部品に `?` が付き、GUI 操作のたびにコマンドを学べるヒントが出ます。 |

レベルは、ヒントの量をまとめて決めるプリセットです。個別の設定で上書きできます。

## コマンドの説明

入力行を、コマンド名、サブコマンド、オプション、引数に分けて、日本語または英語で説明します。

```text
git push -f origin main
→ ローカルの main ブランチを origin に送ります。-f は履歴の不一致を無視して上書きします（危険）。
```

同梱の辞書は、coreutils、git、npm、pnpm、pip、cargo、docker、PowerShell のコマンドなどを収録しています。辞書にないコマンドは、入力中には実行されません。一度実行されたあとに、`--help` の内容を取得して次から使います。

## 補完

入力中に候補を出します。候補は、辞書のサブコマンド、PATH にある実行ファイル、カレントフォルダのファイル、履歴から集められます。

- 候補は `Ctrl+Space` で開き、矢印キーで選び、Enter で確定します。
- ガイドレベル 0 から 2 では、Tab はシェルの補完に渡されます。
- ガイドレベル 3 では、Tab で otterm の候補を確定します。
- 設定の `assist.completion.key` で個別に変えられます。

## 危険ガード

次のような操作は、実行前に確認します。

| 操作 | 確認内容 | 代わりの手 |
| --- | --- | --- |
| `rm -rf` | 中身がすべて消え、ゴミ箱に入りません | 「ゴミ箱に送る」（`otterm trash` に書き換えて実行します） |
| `git push --force` | リモートの履歴を上書きします | `--force-with-lease` |
| `git reset --hard` | 未コミットの変更が消えます | `git stash` |
| `curl ... \| sh` | ダウンロードした内容をそのまま実行します | 先に中身を確認する |
| `Remove-Item -Recurse -Force`（ユーザーフォルダ以上） | ユーザーフォルダ以上の範囲を消します | 対象を絞る |

確認ダイアログには「実行」「代替案で実行」「やめる」があります。ルール単位で「今後は確認しない」を選ぶこともできます。

## エラー助言

コマンドが失敗したとき、出力の内容から原因の候補と次の手を示します。

- `command not found` や `is not recognized`: インストール方法。PATH にあるパッケージマネージャを優先して示します。
- `Permission denied`: 権限の説明と、`sudo` の注意
- `No such file or directory`: パスの確認と、`ls` の提案
- `fatal: not a git repository`: `git init` か、正しいフォルダへの移動
- `EADDRINUSE`: ポートを使っているプロセスの表示
- `ModuleNotFoundError`: `pip install` の提案

助言のボタンは、コマンドを入力欄に入れるだけです。勝手には実行されません。

## 履歴

`Ctrl+R` で otterm の履歴画面を開きます。シェルの履歴と otterm の実行記録をまとめて表示し、フォルダや終了コードで絞り込めます。選んだコマンドは入力欄に入るだけで、すぐには実行されません。

ガイドレベル 0 では、`Ctrl+R` はシェルに渡されます。fzf や atuin を使っている人は、そのままでも大丈夫です。

## パスワード入力の扱い

`sudo` や `ssh` でパスワードを入力しているあいだ、otterm は入力支援を止め、その入力を実行記録にも残しません。
