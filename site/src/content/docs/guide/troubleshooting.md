## セーフモードで起動する

テーマや Mod が原因で画面が使えなくなったときは、セーフモードで起動します。セーフモードでは、同梱の既定テーマに戻り、テーマの CSS と Mod が無効になります。

```sh
otterm --safe-mode
```

otterm が起動しているなら、コマンドパレット（`Ctrl+Shift+P`）の「セーフモードで再起動」か、設定の「詳細」から入ることもできます。画面が操作できないときは、別のターミナルから `otterm --safe-mode` を実行してください。

原因になったテーマや Mod を直すか無効にしてから、通常どおりに起動し直してください。

## クラッシュログ

otterm が異常終了すると、ログが次のフォルダに保存されます。

| OS | 場所 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\otterm\logs\crash-*.log` |

次回起動時、otterm はクラッシュを知らせ、「Issue を作る」ボタンと、ログをコピーするボタンを表示します。ログは自動では送信されません。内容を確認してから、自分で GitHub の Issue に貼り付けてください。

Issue を作る前に、ログに個人情報や秘密情報が含まれていないか確認してください。

## Mod が止まる

Mod が例外を出したり、5 秒以上応答しなかったりすると、その Mod は自動で無効になり、ステータスバーに通知が出ます。続けて 3 回落ちた場合は、自動的に無効のまま残ります。Mod のログは開発者モードで確認できます。

## よくある問題

| 症状 | 対処 |
| --- | --- |
| ブロックの線が出ない、「シェル統合が無効です」と出る | [シェル統合](/guide/shell-integration/) の確認項目を見てください |
| 日本語が豆腐（□）になる | フォント設定の `font.family` に日本語のフォントを追加してください |
| 文字の幅がずれる | `terminal.ambiguous_width` を `wide` に変えてください（日本語環境では CJK ロケールの文字幅を使う場合があります） |
| `Ctrl+C` でコピーできない | Windows では、文字を選択してから押してください。選択していなければ中断になります |
| ワークスペースのコマンドが動かない | ワークスペースを信頼していない可能性があります。[設定](/guide/settings/) の信頼の確認を見てください |
| 起動時に設定の注意が出る | 通知に書かれた項目を見直してください。壊れた値は既定値に戻ります |

## 設定をやり直す

すべての設定を既定に戻すには、`otterm config reset` を実行します。元の設定は `config.toml.bak-reset-<時刻>` に残ります。
