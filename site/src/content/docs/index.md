## どこから読むか

- はじめて使うなら、[はじめに／インストール](/guide/getting-started/) から順に読んでください。
- 設定やキーを変えるなら、[設定](/guide/settings/) と [キーバインド](/guide/keybindings/) です。
- mod を作るなら、[mod 作者ガイド](/mods/) から始めてください。型の詳細は [API リファレンス](/api/) にあります。

> v1.0 は Windows 版から公開しています。macOS / Linux 版は 1.0.x で出します。
