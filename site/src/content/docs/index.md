## どこから読むか

- **はじめて使う人**: [はじめに／インストール](/guide/getting-started/) から順に読んでください。コツメが案内役として画面にいます。
- **設定やキーを変えたい人**: [設定](/guide/settings/) と [キーバインド](/guide/keybindings/) を読んでください。
- **Mod を作りたい人**: [Mod 作者ガイド](/mods/) から始めてください。型の詳細は [API リファレンス](/api/) にあります。

> v1.0 は Windows 版から公開しています。macOS / Linux 版は 1.0.x で出します。
