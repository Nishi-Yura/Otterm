# otterm 1.1 🦦

**何も入っていない状態から始まる otterm** です。Windows（x64）版。

**otterm now starts with nothing added.** For Windows (x64).

## 変わったこと / What changed

- 🧩 **最初は普通のターミナル** — 同梱のものも含めて、mod はすべて最初はオフです。入れたばかりの otterm には、コツメもサイドパネルも出ません。プロンプトはシェル自身のもので、`Ctrl+R`、`Ctrl+Space`、`Shift+Enter` もシェルに届きます。設定 › mod（ステータスバーの「mod」）で、ほしいものだけをオンにして、自分のターミナルに育ててください / **A plain terminal to start with.** Every mod, bundled ones included, starts off: no Pebble, no side panel, the shell's own prompt, and `Ctrl+R`, `Ctrl+Space` and `Shift+Enter` reach the shell. Turn on what you want in Settings › Mods
- ⚡ **おすすめをまとめてオン** — mod の一覧のボタンひとつで、コツメ、辞書、説明、補完、危険ガード、エラー助言、履歴検索、ファイルツリーが入ります / **One button for the recommended set**: Pebble, the dictionary, explanations, completion, the danger guard, error hints, history search and the file tree
- 🦦 **組み込みの機能も mod に** — コツメ（`otterm.mascot`）、履歴検索（`otterm.history-search`）、複数行エディタ（`otterm.multiline-editor`）、プロンプトバー（`otterm.prompt-bar`）を、mod の一覧から入れたり外したりできます / **Built-in features became mods**: Pebble, history search, the multi-line editor and the prompt bar can be switched in the mods list
- 🔗 mod をオンにすると、必要な mod（辞書など）も一緒にオンになります / Turning a mod on also turns on the mods it needs

> [!IMPORTANT]
> **1.0 から更新した場合は、今までどおりです。** 初回起動時に、1.0 で最初からオンだった mod を設定に書き込みます（自分でオフにしていたものは除きます）。
>
> **Upgrading from 1.0 keeps your setup**: on the first start, the mods 1.0 had on by default are written into your settings, except the ones you had turned off.

## 直したこと / Fixes

リサイズとスクロールバック、結合文字、検索、mod の API、設定画面などの 17 件の issue を直しました。セキュリティの修正として、mod のサンドボックスの抜け道（`..` のパス、`PATH` の上書き、`terminal.insert` の制御文字ほか）を塞ぎました。詳しくは [CHANGELOG](https://github.com/Nishi-Yura/Otterm/blob/main/CHANGELOG.md) を見てください。

Fixed 17 issues around resizing and scrollback, combining characters, search, the mod API and the settings screen, and closed gaps in the mod sandbox (`..` paths, overriding `PATH`, control characters through `terminal.insert`, and more). See the [CHANGELOG](https://github.com/Nishi-Yura/Otterm/blob/main/CHANGELOG.md).

## インストール / Install

`otterm_1.1.0_x64-setup.exe` を実行します（ユーザー単位のインストール、管理者権限は不要）。1.0 を使っている場合は、パレットの「更新を確認」からも更新できます。

Run `otterm_1.1.0_x64-setup.exe` (per-user, no admin rights). On 1.0, "Check for updates" in the palette updates in place.

> [!NOTE]
> インストーラにはコード署名がありません（有料のため）。SmartScreen が出たら「詳細情報 → 実行」を選んでください。ファイルが本物かは `SHA256SUMS.txt` で確かめられます。
>
> The installer is not code-signed (signing certificates cost money). If SmartScreen appears, choose "More info → Run anyway". `SHA256SUMS.txt` lets you check the file.
