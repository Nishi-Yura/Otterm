# otterm 1.1

新しく入れた otterm は、何も足していない状態で始まります。Windows（x64）版です。

- 同梱のものも含めて、mod は最初はすべてオフです。コツメもサイドパネルも出ません。プロンプトはシェル自身のもので、Ctrl+R、Ctrl+Space、Shift+Enter もシェルに届きます。
- 設定 › mod（ステータスバーの「mod」）で、ほしいものだけオンにします。「おすすめをまとめてオンにする」で、コツメ、辞書、説明、補完、危険ガード、エラー助言、履歴検索、ファイルツリーが一度に入ります。
- コツメ、履歴検索、複数行エディタ、プロンプトバーも mod になりました。
- mod をオンにすると、必要な mod（辞書など）も一緒にオンになります。

1.0 から更新した場合は、今までどおりです。初回起動時に、1.0 で最初からオンだった mod を設定に書き込みます（自分でオフにしていたものは除きます）。

New installs of otterm start with nothing added. This is the Windows (x64) build.

- Every mod, bundled ones included, starts off. There is no Pebble and no side panel. The prompt is the shell's own, and Ctrl+R, Ctrl+Space and Shift+Enter reach the shell.
- Turn on what you want in Settings › Mods (the "mod" item in the status bar). "Turn on the recommended set" adds Pebble, the dictionary, explanations, completion, the danger guard, error hints, history search and the file tree in one step.
- Pebble, history search, the multi-line editor and the prompt bar are mods now too.
- When you turn on a mod, the mods it needs (the dictionary, for example) are turned on with it.

If you are updating from 1.0, nothing changes for you. On the first start, otterm writes the mods that 1.0 had on by default into your settings, except the ones you had turned off yourself.

## 直したこと

リサイズとスクロールバック、結合文字、検索、mod の API、設定画面などの 17 件の issue を直しました。mod のサンドボックスの抜け道（`..` のパス、`PATH` の上書き、`terminal.insert` の制御文字ほか）も塞ぎました。詳しくは [CHANGELOG](https://github.com/Nishi-Yura/Otterm/blob/main/CHANGELOG.md) を見てください。

## Fixes

17 issues around resizing and scrollback, combining characters, search, the mod API and the settings screen are fixed. Gaps in the mod sandbox (`..` paths, overriding `PATH`, control characters through `terminal.insert`, and more) are closed. See the [CHANGELOG](https://github.com/Nishi-Yura/Otterm/blob/main/CHANGELOG.md).

## インストール

`otterm_1.1.0_x64-setup.exe` を実行します（ユーザー単位のインストール、管理者権限は不要）。1.0 を使っている場合は、パレットの「更新を確認」からも更新できます。

> [!NOTE]
> インストーラにはコード署名がありません（有料のため）。SmartScreen が出たら「詳細情報 → 実行」を選んでください。ファイルが本物かは `SHA256SUMS.txt` で確かめられます。

## Install

Run `otterm_1.1.0_x64-setup.exe` (per-user, no admin rights). On 1.0, "Check for updates" in the palette updates in place.

> [!NOTE]
> The installer is not code-signed (signing certificates cost money). If SmartScreen appears, choose "More info → Run anyway". `SHA256SUMS.txt` lets you check the file.
