# otterm 1.2

シェルが、otterm のウィンドウとは別のプロセスで動くようになりました。Windows（x64）版です。

<p align="center"><img src="https://raw.githubusercontent.com/Nishi-Yura/Otterm/main/assets/readme/keep-ja.png" alt="ウィンドウが落ちても、シェルは動き続け、開き直すと続きが見える" width="720"></p>

- otterm が落ちても、更新や設定の反映で再起動しても、シェルは止まりません。スクロールバックもそのままで、次に開いたウィンドウが同じタブを開き直します。tmux はいりません。
- 普通にウィンドウを閉じたときは、今までどおりシェルも終わります。閉じても残すなら `general.keep_sessions = "always"`、ウィンドウの中で動かすなら `"never"` にします。
- スクロールが続く出力の処理が 2 倍あまり速くなりました（約 30 → 70〜80 MiB/s）。
- `general.restore_session` をオンにすると、前回のタブを同じフォルダで開き直します（初期設定はオフ）。
- Claude Code のように自分でカーソルを描く TUI でも、日本語の変換候補がカーソルの位置に出るようにしました。
- AI の回答を、コツメの言葉ではなく「AI の回答」として出すようにしました。提案されたコマンドには「AI の案です。実行する前に読んでください。」と添えます。
- 画面の言葉、README、サイトの文章を、具体的で飾らない書き方に直しました。

1.1 から更新するとき、この更新の再起動ではまだシェルは残りません（シェルを別のプロセスに置くのは 1.2 からです）。1.2 から先の更新では残ります。

毎日ターミナルで作業する人の目で見直し、次も変えました。

- PowerShell のプロファイル、`~/.bashrc`、`~/.zshrc`、`config.fish` を読んでからシェルを始めます。エイリアスやプロンプトのテーマはほかのターミナルと同じです。素のシェルにしたいときは `shell.user_startup_files = false`。
- vim や less の中では Ctrl+V をそのまま渡します（vim の矩形選択）。貼り付けは Ctrl+Shift+V か Shift+Insert です。
- `otterm --help` と `otterm --version` は表示して終わります。知らないオプションや存在しないパスはエラーにします。
- 辞書にないコマンドの `--help` を裏で読むのは、説明の mod がオンのときだけにしました（`assist.learn_help` で止められます）。mod を入れていない otterm は、あなたが打ったもの以外を起動しません。
- 新しいタブと分割は、手前のペインと同じプロファイルとフォルダで開きます。cmd でもフォルダを引き継ぎ、WSL は 1 行の設定でシェル連携が入ります。MSYS2 と、scoop などで入れた Git Bash も見つけます。
- 危険なコマンドの確認が、ブロックの「もう一度実行」、複数行の貼り付け、mod が書き込むコマンドにも効きます。
- AI に送る内容は、既定で毎回全文を見せてから送ります。
- 履歴で `mkdir -p` や `ssh -p 22` の `-p` の後ろが伏字になっていたのを直しました。
- 文字色を背景に合わせて変える補正（`appearance.minimum_contrast`）を既定でオフにしました。
- 待機中のメモリ（タブ 1 つで約 460〜480 MB、大半は WebView2）を README に載せました。

この 1.2.0 は、10 月 12 日に出した最初の 1.2.0 を 10 月 13 日に差し替えたものです。インストーラとチェックサムは最初の版と違います。最初の 1.2.0 を入れた人は、インストーラを入れ直してください（版番号が同じなので、自動更新では届きません）。

There is now a process of its own for your shells, apart from the otterm window. This is the Windows (x64) build.

- If otterm crashes, or restarts for an update or a setting, your shells keep running with their scrollback, and the next window opens the same tabs again. No tmux needed.
- Closing the window normally still ends the shells. Set `general.keep_sessions = "always"` to keep them then too, or `"never"` to run them inside the window.
- Long scrolling output is parsed a little over twice as fast (about 30 to 70-80 MiB/s).
- `general.restore_session` (off by default) reopens the last tabs in their folders.
- In TUIs that draw their own cursor, such as Claude Code, the IME candidate window opens at that cursor.
- AI answers are shown as "The AI's answer" rather than as Pebble speaking, and suggested commands say they are AI suggestions to read before running.
- The wording across the app, the READMEs and the site was rewritten to be plain and specific.

When you update from 1.1, the restart for this update does not keep your shells yet, because the separate process only arrives with 1.2. Updates after 1.2 will.

After a review from the view of someone who works in a terminal all day, this release also:

- Starts the shell after your PowerShell profile, `~/.bashrc`, `~/.zshrc` or `config.fish`, so aliases and prompt themes are the same as in any other terminal. `shell.user_startup_files = false` starts it as installed.
- Passes Ctrl+V through inside vim and less (vim's visual block). Paste there with Ctrl+Shift+V or Shift+Insert.
- Prints and exits for `otterm --help` and `otterm --version`; an unknown option or a missing path is an error.
- Reads `--help` of commands the dictionary does not know only while the explanation mod is on (`assist.learn_help` turns it off). With no mods, otterm starts nothing you did not type.
- Opens new tabs and splits with the profile and folder of the pane in front. cmd keeps the folder too, WSL gets shell integration with one line of setup, and MSYS2 and Git Bash from scoop and similar places are found.
- Asks before dangerous commands also for a block's "run again", a paste with line breaks, and commands a mod writes.
- Shows the whole AI request every time before it is sent, by default.
- Stops history from hiding the word after `-p` in `mkdir -p` or `ssh -p 22`.
- Turns off the color nudging (`appearance.minimum_contrast`) by default.
- Lists memory while idle in the README (about 460 to 480 MB for one tab, most of it WebView2).

This 1.2.0 replaces the first 1.2.0 build of October 12; it was re-released on October 13. The installer and its checksum differ from the first build. If you installed the first 1.2.0, run the installer again: the version number is the same, so the updater does not offer it.

## インストール

`otterm_1.2.0_x64-setup.exe` を実行します（ユーザー単位のインストール、管理者権限は不要）。1.1 を使っている場合は、パレットの「更新を確認」からも更新できます。

> [!NOTE]
> インストーラにはコード署名がありません（有料のため）。SmartScreen が出たら「詳細情報 → 実行」を選んでください。ファイルが本物かは `SHA256SUMS.txt` で確かめられます。

## Install

Run `otterm_1.2.0_x64-setup.exe` (per user, no admin rights). On 1.1, "Check for updates" in the palette updates in place.

> [!NOTE]
> The installer is not code-signed (certificates cost money). If SmartScreen appears, choose "More info", then "Run anyway". `SHA256SUMS.txt` lets you check the file.
