# otterm 1.0 🦦

最初の安定版です。**Windows（x64）版**のみ。macOS / Linux 版は実機で確かめてから 1.0.x で出します。

The first stable release, **for Windows (x64)**. macOS and Linux builds follow in 1.0.x once they have been checked on real machines.

## できること / Highlights

- 🧭 **打ちながら分かる** — 入力中のコマンドとオプションを、同梱の辞書（164 コマンド）で説明 / Explains the command you are typing (164 bundled commands)
- 🛑 **危ないコマンドの前で止まる** — `rm -rf`、`git push --force` などは、何が消えるかと安全な代わり方を見せてから確認 / Asks before dangerous commands, with what would be lost and a safer way
- 🦦 **コツメ（Pebble）** — 作業に合わせて表情が変わる案内役。設定ひとつで隠せる / A guide whose mood follows your work; one setting hides it
- 🤖 **AI 補助（任意・既定オフ）** — ローカルモデルか自分のキー。送る前に中身を見せ、秘密らしき文字列とホームフォルダのパスは伏せる / Optional AI with a local model or your own key; everything sent is previewed and masked
- 🧩 **mod とストア** — 権限を宣言するサンドボックスの mod。ストアの一覧は署名つき / Sandboxed mods with declared permissions; the store index is signed
- 🧱 ブロック、タブと分割、ワークスペース、検索、圧縮スクロールバック、15 テーマ、キーバインド、設定画面 / Blocks, tabs and splits, workspaces, search, compressed scrollback, 15 themes, key bindings, settings screen
- ⚡ 打鍵遅延 p99 6.2 ms（WebGL2、開発機）/ Typing latency p99 6.2 ms (WebGL2, development machine)
- 🛡️ テレメトリなし・サーバーなし・アカウントなし / No telemetry, no server, no account

## インストール / Install

`otterm_1.0.0_x64-setup.exe` を実行します（ユーザー単位のインストール、管理者権限は不要）。新しいターミナルで `otterm` と打てば起動します。

Run `otterm_1.0.0_x64-setup.exe` (per-user, no admin rights). Then `otterm` works in a new terminal.

> [!NOTE]
> インストーラにはコード署名がありません（有料のため）。SmartScreen が出たら「詳細情報 → 実行」を選んでください。ファイルが本物かは `SHA256SUMS.txt` で確かめられます。
>
> The installer is not code-signed (signing certificates cost money). If SmartScreen appears, choose "More info → Run anyway". `SHA256SUMS.txt` lets you check the file.

自動更新は署名つきです。更新を確認するかは最初の案内で聞かれ、設定でいつでも切り替えられます。 / Updates are signed. The first-run guide asks whether to check for them; the setting can be changed any time.
