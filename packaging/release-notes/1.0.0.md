# otterm 1.0

最初の安定版です。Windows（x64）版のみです。macOS / Linux 版は実機で確かめてから 1.0.x で出します。

The first stable release, for Windows (x64) only. macOS and Linux builds follow in 1.0.x once they have been checked on real machines.

## できること

- 入力中のコマンドとオプションを、同梱の辞書（164 コマンド）で説明します。
- `rm -rf` や `git push --force` などの前で止まります。何が消えるかと、安全な代わりのコマンドを見せてから確認します。
- コツメ（Pebble）は、作業に合わせて表情が変わる案内役です。設定ひとつで隠せます。
- AI 補助は任意で、初期設定はオフです。ローカルモデルか自分のキーを使い、送る前に中身を見せます。秘密らしき文字列とホームフォルダのパスは伏せます。
- mod は、権限を宣言したサンドボックスの中で動きます。ストアの一覧は署名つきです。
- ブロック、タブと分割、ワークスペース、検索、圧縮スクロールバック、15 テーマ、キーバインド、設定画面があります。
- 打鍵遅延は p99 で 6.2 ms です（WebGL2、開発機）。
- テレメトリ、サーバー、アカウントはありません。

## Highlights

- Explains the command and options you are typing, using a bundled dictionary of 164 commands.
- Stops before commands such as `rm -rf` and `git push --force`, showing what would be lost and a safer alternative.
- Pebble is a guide whose mood follows your work. One setting hides it.
- AI help is optional and off by default. It uses a local model or your own key, shows what is sent first, and masks secret-looking strings and home-folder paths.
- Mods run in a sandbox with declared permissions. The store index is signed.
- Blocks, tabs and splits, workspaces, search, compressed scrollback, 15 themes, key bindings and a settings screen.
- Typing latency is p99 6.2 ms (WebGL2, development machine).
- No telemetry, no server, no account.

## インストール

`otterm_1.0.0_x64-setup.exe` を実行します（ユーザー単位のインストール、管理者権限は不要）。新しいターミナルで `otterm` と打てば起動します。

> [!NOTE]
> インストーラにはコード署名がありません（有料のため）。SmartScreen が出たら「詳細情報 → 実行」を選んでください。ファイルが本物かは `SHA256SUMS.txt` で確かめられます。

自動更新は署名つきです。更新を確認するかは最初の案内で聞かれ、設定でいつでも切り替えられます。

## Install

Run `otterm_1.0.0_x64-setup.exe` (per-user, no admin rights). Then `otterm` works in a new terminal.

> [!NOTE]
> The installer is not code-signed (signing certificates cost money). If SmartScreen appears, choose "More info → Run anyway". `SHA256SUMS.txt` lets you check the file.

Updates are signed. The first-run guide asks whether to check for them, and you can change that in settings at any time.
