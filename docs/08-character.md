# 08. キャラクター仕様（Character: コツメ）

## 1. 位置づけ

コツメ（海外名 Pebble）は otterm に住むカワウソのキャラクターで、**ロゴではなく UI の一部**として振る舞う。
役割は 3 つ。

1. **案内役**: 初心者に「次に何をすればいいか」を話しかける
2. **番人**: 危険なコマンドの前で止める。叱らず、代わりの手を差し出す
3. **相棒**: 成功したら喜び、長い処理の間は一緒に待つ。使う人をひとりにしない

コツメは製品の「親切さ」を目に見える形にするための装置であり、上級者には **完全に消せる** ことが設計条件。消しても機能は何も失われない（台詞は通常の UI 文言として表示される）。

## 2. キャラクター設定

| 項目 | 内容 |
| --- | --- |
| 種族 | カワウソ（river otter）。モチーフはコツメカワウソ（Asian small-clawed otter）。器用な前足で貝や甲殻をこじ開け、小石をお手玉のように転がして遊ぶ。ラッコ（sea otter）とは別の動物なので、仰向けで浮かぶ・お腹の上で石を使う、といったラッコの仕草は使わない |
| 名前（日本語） | **コツメ**（仮。判断 E9 で確定する）。コツメカワウソから取り、「コツ（要領）を教えてくれる」に掛ける。ローマ字表記は Kotsume |
| 名前（海外） | **Pebble**（仮。判断 E9 で確定する）。いつも転がして遊んでいる小石から。一般名詞なので商標衝突のリスクが比較的低い。UI 言語が日本語のときはコツメ、それ以外では Pebble と表示する。翻訳ファイルで切り替えるので、コードには名前を直書きしない |
| 性格 | 穏やかで面倒見がよい。慌てない。知らないことを馬鹿にしない。間違えたときは一緒に困る |
| 口調（日本語） | です・ます調で短く。「〜だよ」は使わない。例: 「このフォルダの中身が全部消えます。ゴミ箱に送りますか？」 |
| 口調（英語） | 平易で短い。感嘆符は成功時のみ |
| 持ち物 | お気に入りの小石（前足で転がして遊ぶ。考え事のときに回す）。貝殻（= シェル。前足でこじ開ける。衣装 mod で柄が変わる） |
| しないこと | 勝手にコマンドを実行しない。ユーザーの代わりに Enter を押さない。説教しない。長文を喋らない（吹き出しは 2 文まで） |

## 3. ビジュアル仕様

### 3.1 デザイン原則

- **16 px で判別できるシルエット**。丸い頭、小さな耳、長く太いしっぽ。この 3 要素だけで「コツメ」と分かること
- 本体色は 1 色（茶）+ 顔まわりと喉の明色 + 小石の灰色の 3 色。テーマが変わってもこの色は変えない。暗いテーマでも明るいテーマでも浮かないよう、縁取りを 1 px 持つ
- 線は太め、角は丸く。ピクセル絵ではなくフラットなベクター（SVG）。拡大縮小に耐える
- 顔のパーツは「目」「口」「眉（警告時のみ）」の 3 つで表情を作る。多くを描き込まない

### 3.2 サイズと用途

| サイズ | 用途 |
| --- | --- |
| 16 px | タブアイコン、ステータスバー、ファビコン |
| 24 px | 入力支援バーの定位置、ブロックガター |
| 48 px | 吹き出し付きの案内、エラー助言カード |
| 96 px | オンボーディング、設定画面のコツメ設定、空のタブ |
| 256 px / 512 px | アプリアイコン、ストア、README |

### 3.3 必須アセット

- 表情 4 種 × 48 px（SVG）。16 px / 24 px は表情なし（通常顔のみ）
- アプリアイコンは **コツメの顔**（判断 E3。Ghostty と同じく、アイコン = キャラが最も記憶に残る）。OS ごとのマスク対応: macOS 角丸、Windows 正方、Linux 円。ドックやタスクバーで他アプリと並べたときの視認性を確認する
- ロゴタイプ（「otterm」の文字 + コツメの顔）横組み・縦組み
- ローディング用アニメーション 1 本（前足で小石をお手玉する、1 秒ループ）

### 3.4 制作体制（内製）

デザインは外注せず内製する。そのための作業規約。

| 項目 | 決め事 |
| --- | --- |
| ツール | Inkscape または Figma。最終成果物は **SVG のソース** をリポジトリ（`assets/mascot/src/`）に置く。バイナリの元データ（`.fig` 等）は置かない |
| 構造 | 1 ファイル = 1 表情。レイヤ名を衣装 Slot（`head` / `face` / `body` / `hand` / `shell` / `back` / `effect`）に揃え、`id` 属性で機械的に差し替えられるようにする |
| 色 | SVG 内に色を直書きせず `currentColor` と CSS 変数（`--ot-mascot-body` 等）を使う。縁取りは `stroke` で 1 px 固定 |
| 最適化 | ビルド時に SVGO で最適化し、`id` は保持する。16 px / 24 px 用は別ファイル（表情なし、線を太く） |
| 手順 | 1. 16 px シルエットを先に決める → 2. 48 px の `calm` を描く → 3. 残り 3 表情 → 4. 衣装 Slot のテンプレート → 5. アプリアイコン。順番を守る（小さい方から決めると後で崩れない） |
| レビュー | 各表情を実際の UI に置いたスクリーンショット（ダーク／ライト、16 / 24 / 48 px）を PR に添付。実寸で見て判断する |
| ライセンス | キャラクター画像は本体コード（Apache-2.0）とは別に、**独自の短いキャラクターガイドライン** で扱う（判断 A2）。条文は 3 つだけ: (1) otterm 用の衣装 mod としての改変・再配布は自由、(2) otterm と無関係な商用利用は不可、(3) 別製品のマスコットとしての利用は不可。ファンアートや記事・動画での使用は自由。全文は `assets/mascot/LICENSE.md` に置く |
| 進め方 | **16 px のシルエットを 3 案描いて 1 つ選び**、その後は 1 案を磨く。小さいサイズで判別できないものは大きくしても良くならない（判断 E1） |
| 配色 | 本体の茶、顔まわりの明色、小石の灰の 3 色を HEX で確定し、ダーク／ライト両背景での縁取り色も決める。UI のアクセント色（`--ot-accent`）とは独立にする（判断 E2）。確定値は `assets/mascot/palette.toml` に置く |

## 4. 表情と状態

### 4.1 4 つの表情（mood）

| mood | 顔 | 使う場面 |
| --- | --- | --- |
| `calm` | 通常。半目で穏やか | 待機中、通常の案内 |
| `thinking` | 目を上に、前足で小石を転がしている | コマンド説明の生成中、`--help` 取得中、補完候補の計算中、長い処理の待機 |
| `alert` | 眉が下がり、小石を胸に抱える | 危険コマンド検出、複数行貼り付け確認、終了コード非 0 |
| `happy` | 目を閉じて笑顔、小石を掲げる | コマンド成功（長時間処理の完了時のみ）、チュートリアル達成、mod のインストール完了 |

- `happy` を毎回出すとうるさいので、**10 秒以上かかった処理の成功時だけ** 出す（設定で閾値変更可）
- 表情は 300 ms のクロスフェードで切り替え。`reduced motion` 設定時は即時切替

### 4.2 状態遷移

```
          input-changed（危険なし）           block-end（成功, >10s）
 calm  <------------------------------  thinking  ----------------------->  happy
   |                                       ^                                   |
   | danger 検出 / exit != 0               | before-execute / 説明取得中        | 3 秒後
   v                                       |                                   v
 alert  ------------------------------------+---------------------------------> calm
          ユーザーが選択（実行 / 代替 / やめる）
```

優先順位は `alert > thinking > happy > calm`。複数の要因が同時に起きたら高い方を表示する。

### 4.3 ガイドレベルとの連動

| ガイド Lv | コツメの表示 | 吹き出し |
| --- | --- | --- |
| 0 | 非表示（アプリアイコン以外に登場しない） | なし。台詞は通常の UI 文言として出る |
| 1 | ステータスバーに 16 px。表情のみ変わる | `alert` のときだけ吹き出し |
| 2 | 入力支援バー左端に 24 px | `alert` と初回の案内 |
| 3 | 24 px + 空のタブや設定画面にも 96 px で登場 | 常時。操作の説明、学習ヒントを話す |

- 「初回の案内」は **機能ごとに生涯 1 回** を既定とする（判断 E5）。見た記録は設定フォルダに保存し、設定画面の「案内をもう一度見る」でリセットできる
- ガイドレベルとは独立に、「コツメを表示する」「吹き出しを出す」「表情を変える」を個別にオン／オフできる

## 5. 登場する画面と台詞

### 5.1 登場箇所

| 画面 | 役割 | 例（Lv2、日本語） |
| --- | --- | --- |
| オンボーディング | 進行役。各ステップの説明 | 「はじめまして、コツメです。まず、どのくらい手伝うか決めましょう」 |
| 空のタブ（初回のみ） | 最初の一歩 | 「ここに文字を打って Enter を押すと実行されます。試しに `ls` と打ってみましょう」 |
| 入力支援バー | 説明の語り手。吹き出しではなくバー内テキストとして | 「`git status`: 変更されたファイルの一覧を表示します」 |
| 危険ガードのダイアログ | 止める。代替案を出す | 「これはゴミ箱に入らず、元に戻せません。代わりにゴミ箱へ送りますか？」 |
| エラー助言カード | 原因と次の一手 | 「`npm` が見つかりませんでした。Node.js が入っていないかもしれません」 |
| 長い処理の待機 | 一緒に待つ（thinking 表情、ループアニメ） | 吹き出しなし |
| 処理完了（>10 s） | 喜ぶ | 「終わりました。12 秒かかりました」 |
| チュートリアル達成 | 褒める | 「できました。これで `cd` と `ls` は使えます」 |
| 設定画面「コツメ」タブ | 自分の設定を説明 | 「ここで私の表示を変えられます。消すこともできます」 |
| mod インストール完了 | 変化を知らせる | 「ステータスバーにブランチ名が出るようになりました」 |
| セーフモード起動 | 状況説明 | 「テーマと mod を止めて起動しました。設定から戻せます」 |

### 5.2 台詞の規約

- 2 文まで。1 文は 40 文字以内（日本語）
- 行動を促す文には必ずボタンを添える（「ゴミ箱へ送る」「コマンドを入れる」）。文だけで終わらせない
- 否定語で始めない。「できません」ではなく「〜すると〜できます」
- 技術用語には初出時に短い補足（Lv3 のみ）。例: 「ディレクトリ（フォルダのことです）」
- すべての台詞は翻訳ファイル（Fluent 形式 `locales/*.ftl`。判断 C7）に置き、コードに直書きしない。Fluent は複数形や変数の文法処理を翻訳側で扱えるため、「12 秒かかりました」「1 件のファイル」のような自然文に向く。mod も同じ仕組みで台詞を追加する
- 台詞は `calm / thinking / alert / happy` のどの mood で言うかを翻訳キーと一緒に指定する

## 6. 技術仕様

### 6.1 Slot と配置

- 専用 Slot `mascot` を持つ（[04-ui-theme.md](04-ui-theme.md)）。**既定位置は全ガイドレベルで入力支援バー左端**。入力支援バーのないレイアウト（`minimal`、`classic`）ではステータスバーに移る（判断 E4）
- 配置の選択肢: `assist-bar`（既定）、`statusbar`、`float`（右下フロート、ドラッグで移動可、位置を記憶）、`hidden`。フロートは「コツメをもっと見たい人」向けの設定であり、Lv3 でも既定にはしない（ターミナルを隠さない原則）
- 吹き出しはコツメの位置に応じて上下左右に自動で向きを変える
- ターミナル領域に重ねない（出力を隠さない）。`float` のときだけ重なるが、半透明にして下の文字が読める

### 6.2 コンポーネント構成

```
<Mascot>                       # Slot "mascot" に置かれる本体
  <MascotSprite mood size />   # SVG。衣装レイヤを重ねる
  <SpeechBubble>               # 台詞 + ボタン。キュー制で 1 つずつ表示
</Mascot>

MascotStore                    # 状態（mood、表示設定、衣装、吹き出しキュー）
MoodController                 # イベント → mood の変換（4.2 の遷移）
ReactionRegistry               # mod が追加する反応ルール
OutfitRegistry                 # 衣装の登録・適用
```

- `MoodController` はコアのイベント（`input-changed`、`before-execute`、`block-end` 等）を購読する。コツメ自体は同梱 mod `otterm.mascot` として実装し、他の mod と同じ API を使う
- 吹き出しはキュー制。同時に 1 つしか出さない。`alert` は割り込み優先

### 6.3 mod API（`ctx.mascot`）

```ts
// 話させる。戻り値は閉じられたときに解決する Promise
ctx.mascot.say("ブランチを切り替えました", {
  mood: "happy",
  duration: 3000,                 // ms。0 で手動で閉じるまで
  actions: [{ label: "差分を見る", onClick: showDiff }],
});

// 一時的に表情を変える（指定 ms 後に元に戻る）
ctx.mascot.setMood("thinking", { for: 5000 });

// 反応ルールを追加
ctx.mascot.reactions.add({
  on: "block-end",
  when: b => b.command.startsWith("git push") && b.exitCode === 0,
  mood: "happy",
  say: "i18n:git-status-bar.pushed",
  once: "per-session",            // never | per-session | per-day | always
});
```

- `say` は Lv0 のときは通常のトースト／カード表示に自動で置き換わる。mod 側は分岐しなくてよい
- 1 mod あたり吹き出しは 1 分に 3 回まで（うるさい mod を防ぐ）。超過分は捨ててログに出す
- `say` に `terminal.write` 相当の自動実行ボタンを付けることはできない。ボタンは `insert`（入力欄に入れる）か mod 自身のコマンドのみ

### 6.4 衣装（outfit）mod

```toml
[mod]
id = "example.rakko-winter"
kind = "outfit"
name = "コツメ 冬の装い"

[outfit]
base = "default"                 # 差し替える土台。default | custom（本体ごと差し替え）
layers = [
  { slot = "head", file = "assets/knit-cap.svg" },
  { slot = "hand", file = "assets/mitten.svg" },
  { slot = "shell", file = "assets/shell-snow.svg" },
]

[outfit.moods]                   # 任意。表情ごとに差し替える場合
alert = "assets/alert-override.svg"

[outfit.lines]                   # 任意。台詞の差し替え（翻訳キー単位）
"mascot.greeting" = { ja = "寒いですね。今日も一緒にやりましょう", en = "Cold today. Let's get started." }
```

- 衣装レイヤの Slot: `head`、`face`、`body`、`hand`、`shell`、`back`、`effect`（周囲のエフェクト）
- `base = "custom"` にすると本体 SVG ごと差し替えられる（別キャラにもできる。ただし 4 表情ぶん必要）。**技術的には許可するが、公式レジストリには載せない**（判断 E6）。ブランドの希釈を防ぎつつ、個人がローカルで好きなキャラに変える自由は奪わない
- 同梱衣装: `default`、`developer`（眼鏡 + マグカップ）、`pixel`（ドット絵版）。季節衣装は公式別配布
- 衣装は設定画面「コツメ」タブで試着・切替。ワークスペースごとに別衣装も可

### 6.5 アクセシビリティ

- コツメの台詞は `aria-live="polite"`（`alert` は `assertive`）でスクリーンリーダーに読まれる
- 表情だけで意味を伝えない。必ずテキストかアイコンが伴う
- アニメーションは `reduced motion` で停止。点滅は使わない

## 7. やらないこと

- ユーザーの作業中に勝手に話し出さない（イベント起因のみ。時間経過で雑談しない）
- 音声を出さない（衣装 mod で効果音を足すのは可。既定はオフ）
- 外部に何も送らない（コツメは完全にローカルで動く。AI mod が入っても台詞生成は mod 側の責任で、コツメ本体は通信しない）
- 課金・ガチャ的な要素を持ち込まない。衣装は mod として無料で配れる仕組みにする
