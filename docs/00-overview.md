# 00. 概要（Overview）

## 1. otterm とは

otterm（オッターム）は、**「ターミナルを使うハードルを限界まで下げつつ、上級者が改造し尽くせる余地を残す」** ことを目的としたクロスプラットフォームのターミナルエミュレータです。

従来のターミナルは次の 2 つの前提で作られてきました。

1. 使う人はコマンドをすでに知っている
2. 見た目や挙動の変更は設定ファイルを手で書いて行う

otterm はこの 2 つを前提にしません。

- コマンドを知らなくても、**画面を見れば次に何をすればいいか分かる**
- 設定ファイルを書かなくても、**GUI と mod で見た目・機能を変えられる**
- それでいて、**普通のターミナルとして bash / zsh / PowerShell / cmd をそのまま動かせる**

## 2. 一言で言うと

> 「ゲームの mod 文化を持ち込んだ、初心者にも開発者にも優しいターミナル」

### 名前とキャラクター

- **otterm** = otter（カワウソ）+ term（terminal）。Ghostty の ghost + tty と同じ作り
- カワウソ（特にコツメカワウソ）は器用な前足で貝（**shell**）をこじ開ける。「シェルを解きほぐして分かりやすくする」製品の役割そのもの
- カワウソは家族で暮らし、鳴き声で呼び合う。「ひとりで黒い画面に向き合わせない」という姿勢の象徴
- 画面の中にはカワウソのキャラクター **コツメ**（海外名 **Pebble**）が住んでいて、案内・警告・励ましを担当する。ロゴとしてだけでなく UI の一部として振る舞う。詳細は [08-character.md](08-character.md)
- mod でコツメの衣装や小物を着せ替えられる。「mod を入れると見た目が変わる」をキャラでも体験できる

## 3. ターゲットユーザー

| 区分 | 具体像 | otterm が提供する価値 |
| --- | --- | --- |
| 初心者 | プログラミング学習を始めた人、授業で "黒い画面" を使わされて困っている人、CLI ツールを渡されただけの非エンジニア | コマンドの意味がその場で分かる、ファイルをクリックで開ける、壊しそうな操作は事前に警告される |
| 日常利用者 | Git / npm / Docker などを毎日叩く開発者、インフラ運用者 | 軽量・高速、タブ／分割、履歴検索、シェル統合による "コマンド単位" の操作、豊富な mod |
| 改造好き | ターミナルの見た目に強いこだわりがある人、自作ツールを組み込みたい人 | テーマ・レイアウト・パネル・コマンドをすべて mod として作れる公開 API |
| 配布者 | チーム・教育機関・OSS プロジェクト | 「この mod を入れればうちの環境向けに整う」という配布パッケージを作れる |

## 4. 設計原則（Design Principles）

1. **まず動く、普通のターミナルであること**
   - どんな機能を足しても、既存シェルとの互換性・レンダリング速度・入力遅延を犠牲にしない。
   - otterm 独自要素は全部オフにできる。オフにすれば "ただの速いターミナル" になる。
2. **知らないことを恥ずかしがらせない**
   - エラーをそのまま出さず、「何が起きたか」「次に何をするか」を添える。
   - 「ヘルプを読め」で終わらせず、画面の中で答える。
3. **怖い操作には柵をつける**
   - `rm -rf`、`git push --force`、`DROP TABLE` などは実行前に確認レイヤを挟める（既定でオン、上級者はオフ可）。
4. **すべては mod で拡張できる**
   - コア機能自体も "同梱 mod" として実装し、同じ API で作られている。ユーザー mod にできないことをコア mod だけがやる、という例外を作らない。
5. **設定は GUI でも、ファイルでも**
   - GUI で変えたものは人間が読めるファイル（TOML）に書き出される。dotfiles 管理も可能。
6. **見た目は制約しない**
   - フォント、配色、角丸、透過、背景画像、レイアウトまで CSS 相当の自由度で変更できる。

## 5. 他ターミナルとの位置づけ

| 製品 | 強み | otterm との違い |
| --- | --- | --- |
| Windows Terminal / iTerm2 / GNOME Terminal | OS 標準に近い安定性 | 初心者支援・mod エコシステムがない |
| Alacritty / WezTerm / Kitty | GPU 描画で高速、設定ファイルで細かく制御 | 設定ファイル前提で初心者向けではない。Lua/設定による拡張はあるが「入れるだけ」の mod 配布文化はない |
| Ghostty | ネイティブ GUI と速さの両立、かわいいマスコット | プラグイン機構を意図的に持たない。otterm は速さを「区別がつかない」まで追い（[09-performance.md](09-performance.md)）、改造の自由度とキャラクターが UI に住む点で差を付ける |
| Warp | AI 補助、ブロック単位 UI、初心者に優しい | クローズドで拡張不可、アカウント必須。otterm はオフライン・OSS・mod で同等以上の体験を狙う。AI は「コツメに聞く」形で提供し、自律実行はしない（[10-ai-assist.md](10-ai-assist.md)） |
| Hyper | JS プラグイン | 重い・遅い。otterm はネイティブ描画で軽量に、かつ mod に権限モデルを持たせる |
| Tabby | 多機能、プラグインあり | 多機能ゆえ複雑。otterm は "初期状態はシンプル、必要なら mod" の方向 |

otterm の独自性は次の 3 点に集約されます。

1. **初心者モードと上級者モードが同じ製品の中で連続している**（段階的に剥がせるガイド）
2. **mod を入れるだけで体験が変わる**（Minecraft の Forge / Fabric、Factorio の mod ポータルに近い体験）
3. **コアも mod も同じ API** で作られているため、拡張の天井がない

## 6. やらないこと（Non-Goals）

- シェルそのものを自作しない（bash / zsh / fish / PowerShell / cmd / nushell をそのまま使う）
- エディタになろうとしない（簡易プレビューと "外部エディタで開く" までに留める）
- SSH クライアント機能を v1 のコアに入れない（mod で提供）
- クラウド同期・アカウント機能をコアに入れない（mod / 外部ツールで提供）
- AI 機能をコアに入れない（公式 mod `otterm.ai-assist` として同梱するが既定オフ。API キーはユーザーが管理し、ローカルモデルも選べる）
- AI にコマンドを自律実行させない（提案は入力欄に入るだけ。多段タスクも 1 ステップずつ人が承認）
- 独自のスクリプト言語を作らない（mod は TypeScript / JavaScript、将来 WASM）

## 7. 対応プラットフォーム（v1）

| OS | 優先度 | 備考 |
| --- | --- | --- |
| Windows 11、Windows 10 22H2 以上 | 最優先 | ConPTY 利用。PowerShell 7 / Windows PowerShell / cmd / WSL / Git Bash。WebView2 は Evergreen を使用（判断 A6、C8） |
| macOS 13 以上 | 高 | zsh / bash / fish |
| Linux（Ubuntu 22.04 相当以上、X11 / Wayland 両対応） | 高 | bash / zsh / fish / nushell。WebKitGTK 2.40 以上 |

## 8. 成功指標（v1 時点の目安）

- 初めてターミナルを触る人が、ガイドだけで「フォルダを移動してファイル一覧を見て、ファイルを開く」までたどり着ける
- 既存ターミナルユーザーが乗り換えたとき、入力遅延・描画速度で不満を感じない（目標値は [01-requirements.md](01-requirements.md) 参照）
- 公式 mod ストアに、テーマ系・機能系あわせて 30 以上の mod が並んでいる
- mod の作成が「テンプレを clone して 30 分で動く」レベルに簡単

## 9. 用語集

| 用語 | 意味 |
| --- | --- |
| セッション | 1 つのシェルプロセスとそれに紐づく画面。タブや分割ペインの中身 |
| ブロック | シェル統合によって区切られた「1 コマンドの入力 + 出力」の単位 |
| mod | otterm を拡張するパッケージ。テーマ・機能・パネル・コマンドなどを含む |
| 同梱 mod | otterm 本体に最初から入っている mod。コア機能の多くはこれ |
| パネル | ターミナル画面の横や下に出せる補助 UI（ファイルツリー、ヒント等） |
| コマンドパレット | `Ctrl+Shift+P` で開く、全操作を検索して実行できる窓 |
| ガイドレベル | 初心者支援の強さ（0: なし 〜 3: 手取り足取り） |
| コツメ | otterm に住むカワウソのキャラクター。案内役。表示量はガイドレベルに連動し、完全に隠すこともできる |
| 衣装（Outfit） | コツメの見た目を変える mod の種類。帽子・小物・色違い・別ポーズなど |
| ワークスペース | 複数セッション・レイアウト・設定をまとめた単位。プロジェクトごとに切り替える |
