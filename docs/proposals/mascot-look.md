# キャラクターの見た目と名前の案（判断 E9 用、下書き）

キャラクターはラッコではなく **カワウソ**（モチーフはコツメカワウソ）。ラッコ特有の仕草（仰向けで浮かぶ、お腹の上で石を使う）は使わない。
見た目と名前はユーザーが決める。ここにあるのは比較用の下書きで、どれも確定ではない。

- 実寸比較: [mascot-look.html](mascot-look.html)（ダーク／ライト背景 × 16 / 24 / 48 / 96 px）
- SVG: `assets/mascot/drafts/`

## カワウソらしさの要点

ラッコやクマに見えないための特徴。どの案もこれを守る。

- 耳は **小さく、頭の横の低い位置**（大きな丸耳だとクマに見える）
- 頭は **平たく横に広い**。マズル（口元）が左右にふくらみ、ひげの点がある
- 体は **細長く**、しっぽは **太く長く根元が太い**
- 喉から顔の下半分が明るい色（コツメカワウソの特徴）
- 前足が器用。小石や貝を前足で持つ

組み合わせの例: **アイコンと 16/24 px は A、案内の吹き出しは B、定位置は C**。同じキャラクターの別ポーズとして揃えられる。

### ターミナルの中（文字だけ）で出す場合

画像を出せない場面（`otterm` CLI の出力、SSH 先、Lv0 のテキストだけの案内）用の文字案。2 行以内、全角幅の差で崩れない ASCII のみ。

```
  o    o        ( o.o )~      (`·ω·´)ノ●
 ( ·ᴥ· )~       /> o <\
```

- 1 案目: 横の小耳と長いしっぽ（`~`）
- 2 案目: 小石を抱える
- 3 案目: 顔文字風（`●` が小石）。CJK 幅の扱いに注意

## 名前の候補

旧名「ラコ / Kelp」はラッコ由来なので使えない。ドキュメントは仮に **コツメ / Pebble** で書き換えてある（一括置換で差し替え可能）。

| 日本語 | 海外 | 由来 | 気になる点 |
| --- | --- | --- | --- |
| **コツメ**（仮） | **Pebble**（仮） | コツメカワウソ。「コツを教える」に掛ける。Pebble はいつも転がしている小石 | Pebble はスマートウォッチの名前でもある |
| オッタ | Otta | otter をそのまま短く | 由来が平凡 |
| おっと | Otto | 日本語の「おっと（危ない）」= 危険コマンドで止める役に掛ける | Otto は大手企業名と重なる（商標の確認が要る） |
| こいし | Pip | 小石。Pip は「小さな種・点」 | 日本語名と海外名の意味がずれる |
| ホルト | Holt | holt = カワウソの巣穴。「安心していられる場所」 | 日本語だと可愛さが弱い |
