# 04. UI・テーマ仕様（UI & Theming）

## 1. 画面構成

```
+------------------------------------------------------------------+
| タイトルバー（OS ネイティブ or カスタム）                           |
+------------------------------------------------------------------+
| タブバー  [ ~/proj  x ] [ build  x ] [ + ]            [ 検索 ][設定]|
+----------+-------------------------------------------+-----------+
|          |                                           |           |
| 左パネル |          ターミナル領域                     | 右パネル  |
| (ファイル |        （ペイン分割可）                     | (ヒント／  |
|  ツリー) |                                           |  mod 任意)|
|          |                                           |           |
|          +-------------------------------------------+           |
|          | 入力支援バー（説明 / 危険バナー / 補完）    |           |
+----------+-------------------------------------------+-----------+
| 下パネル（任意: エラー助言、ワークフロー、ログ）                      |
+------------------------------------------------------------------+
| ステータスバー  CWD | ブランチ | 終了コード | ガイド Lv | mod 状態   |
+------------------------------------------------------------------+
```

### 1.1 領域（Slot）

mod や設定が UI を置ける場所を **Slot** として固定名で定義する。

| Slot 名 | 位置 | 置けるもの |
| --- | --- | --- |
| `titlebar.left` / `titlebar.right` | タイトルバー | 小ボタン |
| `tabbar.before` / `tabbar.after` | タブバーの両端 | ボタン、ドロップダウン |
| `tab.decoration` | 各タブの中 | バッジ、アイコン |
| `sidebar.left` / `sidebar.right` | サイドパネル | パネル（タブ切替で複数可） |
| `panel.bottom` | 下パネル | パネル |
| `terminal.overlay` | ターミナル領域の上に重なる層 | トースト、フローティング UI |
| `assist.bar` | 入力支援バー | 説明、バナー |
| `mascot` | コツメの定位置（既定: 入力支援バーの左端。設定で右下フロート／ステータスバーに変更可） | コツメ本体と吹き出し。mod は衣装と台詞を追加できる |
| `block.gutter` | 各ブロックの左 | アイコン、ボタン |
| `block.footer` | 各ブロックの直後 | カード（エラー助言など） |
| `statusbar.left` / `statusbar.right` | ステータスバー | テキスト、アイコン、ミニグラフ |
| `context.terminal` / `context.tab` / `context.file` | 右クリックメニュー | メニュー項目 |

- Slot の表示／非表示、位置（左右・上下の入れ替え）、幅、順序は設定画面でドラッグして変更できる
- タブバーは「上」「下」「左（縦）」「非表示（タブが 1 つのとき）」を選べる

### 1.2 レイアウトプリセット

| 名前 | 内容 | 想定 |
| --- | --- | --- |
| `minimal` | ターミナルのみ。タブは複数時のみ表示 | 上級者 |
| `classic` | タブ + ステータスバー | 一般 |
| `guided`（既定 Lv2） | classic + 左ファイルツリー + 入力支援バー | 初心者〜一般 |
| `ide` | guided + 右パネル + 下パネル | 多機能派 |
| `cards` | guided のブロック表示を Warp 風のカード型（余白と枠）に変えたもの | ブロック単位で見たい人 |

プリセットは出発点であり、変更すると「カスタム」になる。保存して名前を付けられ、mod として共有できる。

## 2. テーマ

### 2.1 テーマの構造

テーマは TOML（または mod 内 JSON）で、3 層に分かれる。

1. **ターミナル色**: ANSI 16 色、前景、背景、カーソル、選択、太字色、リンク色
2. **UI トークン**: 背景・前景・アクセント・境界・危険・成功・警告の各色、角丸、影、フォント、間隔
3. **スタイル上書き**: CSS（任意、上級者向け）

```toml
[theme]
name = "otterm Dark"
appearance = "dark"            # light | dark （OS 追従時の切替に使う）

[theme.terminal]
foreground = "#d4d4d4"
background = "#1e1e1e"
cursor     = "#ffffff"
selection  = "#264f78"
ansi = ["#000000", "#cd3131", "#0dbc79", "#e5e510", "#2472c8", "#bc3fbc", "#11a8cd", "#e5e5e5"]
bright = ["#666666", "#f14c4c", "#23d18b", "#f5f543", "#3b8eea", "#d670d6", "#29b8db", "#ffffff"]

[theme.ui]
bg          = "#181818"
bg-elevated = "#222222"
fg          = "#e6e6e6"
fg-muted    = "#9a9a9a"
accent      = "#4f8cff"
border      = "#2e2e2e"
danger      = "#ff5c5c"
success     = "#3ddc84"
warning     = "#ffb020"
radius      = "8px"
shadow      = "0 4px 16px rgba(0,0,0,.4)"
font-ui     = "Inter, 'Noto Sans JP', system-ui"

[theme.window]
opacity = 1.0               # 0.0 - 1.0。既定は不透過（可読性と描画性能のため。判断 I6）。透過はテーマ側で選ぶ
blur    = false             # OS 対応時のみ。opacity < 1.0 のときだけ意味を持つ
background-image = ""       # パスまたは URL（ローカルのみ推奨）
background-fit   = "cover"
padding = 12

[theme.css]
file = "overrides.css"      # 任意
```

### 2.2 CSS 変数の公開

UI 側は `theme.ui` の全キーを `--ot-<key>` として `:root` に展開する。ターミナル色も `--ot-term-ansi-0` 〜 `--ot-term-bright-7` として公開。
mod のパネル UI もこれらの変数だけを使うことを規約とし、テーマを変えればすべての mod が追従する。

### 2.3 スタイル上書き（CSS）

- テーマは `overrides.css` を持てる。本体 UI の各要素には安定した `data-ot` 属性（例: `[data-ot="tab"]`、`[data-ot="statusbar"]`）を付け、クラス名ではなくこの属性をセレクタとして保証する
- 破壊的な CSS（`display:none` でタブバーを消す等）も許容する。「見た目を自由自在に」が方針
- CSS が原因で UI が操作不能になった場合に備え、「セーフモード（テーマ・mod 無効）」で起動できる。`otterm --safe-mode`、コマンドパレットか設定 › 詳細の「セーフモードで再起動」。セーフモードでは同梱の既定テーマ、CSS の上書きなし、透過・背景画像なし、mod を起動しない。上部の帯から通常モードで再起動できる（判断 M17。起動時の `Shift` 押下は見送り）

### 2.4 同梱テーマ

- otterm Dark / otterm Light（既定、WCAG AA 準拠）
- High Contrast
- 人気配色の移植: Catppuccin（4 種）、Dracula、Nord、Solarized（2 種）、Gruvbox（2 種）、Tokyo Night、One Dark
- 既存形式のインポート: iTerm2 `.itermcolors`、Windows Terminal `schemes`、VS Code テーマの `terminal.*`、Alacritty / WezTerm の配色（変換ツールを CLI に同梱）

### 2.5 ライブ編集

- 設定画面の「テーマ」タブで色をピッカーで変えると即時反映
- 「このテーマを保存」でユーザーテーマに。「mod として書き出す」でフォルダ生成

## 3. フォント

| 設定 | 既定 | 備考 |
| --- | --- | --- |
| `font.family` | OS ごと（Windows: Cascadia Code、macOS: SF Mono / Menlo、Linux: DejaVu Sans Mono）+ Nerd Font 検出 | 複数指定でフォールバック |
| `font.size` | 14 | 単位は CSS ピクセル。OS の表示スケールに追従（判断 I9）。`Ctrl+=` / `Ctrl+-` / `Ctrl+0` |
| `font.weight` / `font.weight_bold` | 400 / 700 | |
| `font.line_height` | 1.2 | |
| `font.letter_spacing` | 0 | |
| `font.ligatures` | true | |
| `font.cjk_family` | 自動（OS 内蔵。Windows: BIZ UDGothic → MS Gothic、macOS: ヒラギノ角ゴシック、Linux: Noto Sans CJK JP があればそれ） | 日本語用の別フォント指定。同梱はしない（配布サイズが 15 MB 以上増えるため）。見つからないときだけ Noto Sans CJK のダウンロードを案内（判断 I8） |
| `font.fallback_emoji` | 自動 | |

- 設定画面でフォントのプレビュー（日本語・絵文字・リガチャ・Nerd Font アイコンの見本行）
- **Symbols Nerd Font Mono（記号のみ、SIL OFL）を本体に同梱**し、フォールバックの最後に常に入れる（判断 B14）。これで Nerd Font を知らない初心者でも、プロンプトや `ls` のアイコンが四角にならない。本文フォントと日本語フォントは OS 既定を使い、同梱しない
- 文字の整形とラスタライズは Rust 側で行う（[03-core-features.md](03-core-features.md) §2.3、判断 C3 / C4）。WebView の `font-family` はターミナル領域には使わず、UI 部分（タブ、パネル）にだけ使う

## 4. アニメーションとフィードバック

- カーソル: ブロック／アンダーライン／バー、点滅、滑らかな移動（オフ可）
- タブ切替・パネル開閉は 120 ms 以下のトランジション。`reduced motion` の OS 設定に従う
- ベル: 視覚（フラッシュ）／音／タブバッジ。既定は視覚 + バッジ
- 色覚多様性への配慮（判断 I15）: 危険・成功・警告は色に加えて **必ずアイコンか形で区別**する（ブロックガターの赤は「×」アイコンを伴う、危険バナーは縞模様の縁を持つ、など）。OS のハイコントラスト設定を検出したら High Contrast テーマに自動で切り替え、解除されたら元に戻す
- 長時間コマンド（既定 10 秒超）が終了したとき、ウィンドウが非アクティブなら OS 通知（オフ可）

## 5. アクセシビリティ

- すべてのインタラクティブ要素に `aria-label`、フォーカスリング
- ターミナル内容はスクリーンリーダー向けに「ライブリージョン」として直近の出力行を提供（オン／オフ）
- 全操作にキーボードショートカットまたはコマンドパレット経由の到達手段
- UI スケール（80 %〜200 %）

## 6. 設定画面

- 左にカテゴリ、右にフォーム。検索ボックスで設定名・説明を横断検索
- カテゴリ: 一般 / 外観 / フォント / ターミナル / プロファイル / シェル統合 / 入力支援 / キーバインド / mod / ワークスペース / 詳細（TOML を直接編集）
- フォームは設定スキーマ（JSON Schema）から自動生成し、mod が自分の設定を同じ仕組みで追加できる
- 変更は即時反映、かつ `config.toml` に書き戻す。ファイル側を手で編集した場合も即時反映（監視）
