# 貢献について / Contributing

- mod を載せたい方: [README.md](README.md) の「mod を登録する」を読み、PR を開いてください。
- PR では `node scripts/validate.mjs` が通ることを確認してください（CI でも実行されます）。
- `index.json` は手で編集せず、`node scripts/build-index.mjs` で生成してください。
- 1 PR につき 1 mod にしてください。
- 無料の mod のみ掲載できます（D9）。

Submit one mod per PR. Run `node scripts/validate.mjs` before opening it. Do not edit `index.json` by hand. Only free mods are accepted.
