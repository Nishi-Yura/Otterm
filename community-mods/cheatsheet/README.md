# キー早見表 / Key cheatsheet

otterm の主な既定キーを、サイドパネル（右）に分類して表示します。

A right sidebar panel listing otterm's main default shortcuts, grouped.

## 使い方 / Usage

- コマンドパレットで「キー早見表を開く」（Open key cheatsheet）を実行します。
- 表示の内容は、Windows / Linux は docs/06 の §5.2、macOS は §5.2.1 に従います。macOS では §5.2.1 に載っているキーだけを表示します。
- 表示されるのは既定のキーです。設定で変えたキーは、設定の値が優先されます。

- Run "Open key cheatsheet" from the command palette.
- The list follows docs/06 §5.2 (Windows / Linux) and §5.2.1 (macOS). On macOS only the keys that §5.2.1 lists are shown.
- These are default keys. Keys changed in Settings take precedence.

## 権限 / Permissions

なし。ターミナルの内容は読まず、ファイルにもネットワークにもアクセスしません。

None. The mod does not read the terminal, files or the network.
