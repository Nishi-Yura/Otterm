# コツメ 冬支度 / Pebble in winter

`nishi-yura.outfit-winter`

## 日本語

コツメの着せ替えです。赤いニット帽（ぽんぽんつき）と、おそろいのミトン。設定 › コツメ で着替えられます。4 つの表情すべてにかぶさります。権限は使いません。

## English

An outfit for Pebble: a red knit hat with a pompom and matching mittens. Change outfits in Settings › Pebble. The layers sit on top of all four moods. It uses no permissions.
