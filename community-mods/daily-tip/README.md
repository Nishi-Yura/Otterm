# 今日のコマンド / Command of the day

`nishi-yura.daily-tip`

## 日本語

otterm を起動して少しすると、コツメが同梱の辞書からコマンドを 1 つ紹介します（1 日 1 回）。名前と一行の説明、例があれば「例を入力欄に入れる」ボタンが出ます。例は入力欄に入るだけで、実行するのは Enter を押したあなたです。「ほかのも見る」や、パレットの「今日のコマンドを見る」で、いつでも別のコマンドを見られます。

紹介するのは、どの OS でも使える（または Windows 標準の PowerShell の）コマンドで、単体では危険でないものだけです。最後に出した日を mod のストレージに記録します。権限は使いません。案内レベル 0 では吹き出しの代わりにトーストになります。

### 設定

- `auto_show`（既定: オン）: 起動時に 1 日 1 回自動で出すかどうか。オフにしてもパレットからは見られます

## English

Shortly after otterm starts, Pebble introduces one command from the bundled dictionary, once a day: its name, a one-line summary and, when the entry has one, a button that puts an example into the input line. Nothing runs until you press Enter. "Another one" and the palette command "Show a command of the day" show more at any time.

Only commands that work on every platform (or in PowerShell, the default shell on Windows) and are not dangerous on their own are picked. The day of the last tip is kept in the mod's storage. It uses no permissions. At guide level 0 the bubble becomes a toast.

Setting: `auto_show` (default on). When off, tips are still available from the palette.
