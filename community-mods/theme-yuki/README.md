# 雪 / Yuki

雪景色のような、青みがかった白の明るいテーマです。背景はわずかに青い白、文字は濃い藍鼠で、前景と背景のコントラスト比は 11.9:1 です。アクセントは冬空の青。

## インストール

otterm の mod として読み込みます。`theme.toml` が配色を定義します。

## English

A light theme in cool snow whites and winter blues. The background is a faintly blue white, the text a deep slate; the foreground-to-background contrast ratio is 11.9:1.
