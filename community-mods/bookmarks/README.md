# フォルダのしおり / Folder bookmarks

`nishi-yura.bookmarks`

## 日本語

左のサイドバーに「フォルダのしおり」パネルを追加します。「このフォルダをしおりに追加」（パレット、パネルのボタン、提案キー `Ctrl+Shift+Alt+B`）で、いま見ているターミナルのフォルダを登録します。しおりをクリックすると、そのシェルに合わせてクォートした `cd` が入力欄に入ります。実行するのは Enter を押したあなたです。右クリックで、並べ替え、ファイルマネージャーで開く、しおりを外す、ができます。

しおりは mod のストレージ（この PC の中）に保存します。権限は使いません。

## English

Adds a "Folder bookmarks" panel to the left sidebar. "Bookmark this folder" (palette, the panel button, suggested key `Ctrl+Shift+Alt+B`) saves the focused terminal's folder. Clicking a bookmark puts a `cd`, quoted for that shell, into the input line; nothing runs until you press Enter. The context menu reorders, opens the folder in the file manager, or removes the bookmark.

Bookmarks are kept in the mod's storage on this PC. It uses no permissions.
