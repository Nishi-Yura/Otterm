# 時計 / Clock

`nishi-yura.clock`

## 日本語

ステータスバーの右側に現在時刻を表示します。日付も表示できます。権限は使いません。

### 設定

- `format`（既定: `HH:mm`）: `HH:mm`、`HH:mm:ss`、`h:mm a` から選びます
- `show_date`（既定: オフ）: オンにすると `2026-10-12 14:05` のように日付を前に付けます

## English

Shows the current time at the right of the status bar, optionally with the date. It uses no permissions.

Settings: `format` (default `HH:mm`; also `HH:mm:ss` and `h:mm a`) and `show_date` (default off; when on, the date is shown before the time, for example `2026-10-12 14:05`).
