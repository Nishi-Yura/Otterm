# カワウソの夜 / Kawauso Night

夜の川辺にいるカワウソをイメージした暗いテーマです。背景は深い茶色がかった炭色、文字や線は毛並みのような温かい茶色、アクセントは川の青緑色です。文字と背景のコントラスト比は 12.8:1 です。

## インストール

otterm の mod として読み込みます。`theme.toml` が配色を定義します。

## English

A dark theme inspired by a river otter at night. The background is a deep brown-charcoal, text uses warm fur tones, and accents use river teal. Foreground-to-background contrast is 12.8:1.
