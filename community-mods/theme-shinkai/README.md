# 深海 / Shinkai

深い海の底のようなテーマです。背景は光の届かない濃紺、文字は薄い水色、アクセントは発光するような青緑。前景と背景のコントラスト比は 13.3:1 です。

## インストール

otterm の mod として読み込みます。`theme.toml` が配色を定義します。

## English

A dark deep-sea theme: a navy background where no light reaches, pale aqua text and a glowing teal accent. The foreground-to-background contrast ratio is 13.3:1.
