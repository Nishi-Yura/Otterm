# 夕焼け / Yuyake

夕焼け空のテーマです。背景は暮れかけた紫、文字はあたたかい生成り色、アクセントは沈む太陽の橙。前景と背景のコントラスト比は 12.6:1 です。

## インストール

otterm の mod として読み込みます。`theme.toml` が配色を定義します。

## English

A dark sunset theme: a dusk-purple background, warm cream text and a setting-sun orange accent. The foreground-to-background contrast ratio is 12.6:1.
