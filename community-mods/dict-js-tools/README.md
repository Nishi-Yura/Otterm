# JS 開発ツールの辞書 / JS dev tools dictionary

`vite`、`eslint`、`prettier`、`jest`、`vitest`、`tsx`、`turbo` の主な使い方を、日本語と英語で説明します。`node`、`npm`、`npx`、`pnpm`、`yarn` などは組み込みの辞書にあるため、この mod には含みません。

`jest -u` と `vitest run -u` は、スナップショットを今の出力で書き換えるため、注意を表示します。

## インストール

otterm の mod として読み込みます。辞書データは `dictionary/` フォルダにあります。

## English

A Japanese and English dictionary for `vite`, `eslint`, `prettier`, `jest`, `vitest`, `tsx` and `turbo`. `node`, `npm`, `npx`, `pnpm` and `yarn` are already in the bundled dictionary, so they are not included here.

`jest -u` and `vitest run -u` rewrite snapshots to the current output, so they show a warning.
