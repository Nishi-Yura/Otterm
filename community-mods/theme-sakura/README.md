# 桜 / Sakura

桜色のやわらかい配色の明るいテーマです。背景は温かみのある白、文字は濃い紫がかった茶色で、読みやすさ（前景と背景のコントラスト比 10.2:1）を優先しています。

## インストール

otterm の mod として読み込みます。`theme.toml` が配色を定義します。

## English

A light theme with soft cherry-blossom pinks on a warm white background. Text is a deep plum-brown; the foreground-to-background contrast ratio is 10.2:1.
