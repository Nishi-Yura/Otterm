# モダン CLI ツールの辞書 / Modern CLI tools dictionary

`rg`（ripgrep）、`fd`、`bat`、`fzf`、`eza`、`zoxide`（`z` / `zi`）、`tldr`、`hyperfine` の主な使い方を、日本語と英語で説明します。`grep`、`find`、`cat`、`ls`、`cd` の速くて見やすい代わりになる道具と、使い方を短く調べる・時間を測る道具です。インストール方法（winget / scoop / brew / apt / cargo など）も載せています。

危険な操作はありません。`fd -X rm -r` のように削除コマンドと組み合わせたときは、組み込みの `rm` のルールが働きます。

## インストール

otterm の mod として読み込みます。辞書データは `dictionary/` フォルダにあります。

## English

A Japanese and English dictionary for `rg` (ripgrep), `fd`, `bat`, `fzf`, `eza`, `zoxide` (`z` / `zi`), `tldr` and `hyperfine`: the faster, friendlier replacements for `grep`, `find`, `cat`, `ls` and `cd`, plus the tools for quick usage lookups and timing. Install commands (winget / scoop / brew / apt / cargo, ...) are included.

Nothing here is dangerous by itself; when combined with a delete, such as `fd -X rm -r`, the bundled `rm` rules apply.
