# Python 開発ツールの辞書 / Python dev tools dictionary

`pytest`、`ruff`、`black`、`mypy`、`jupyter`、`pre-commit` の主な使い方を、日本語と英語で説明します。`python`、`pip`、`uv` は組み込みの辞書にあるため、この mod には含みません。

`pre-commit install -f` は既存の git hook を置き換えるため、注意を表示します。

## インストール

otterm の mod として読み込みます。辞書データは `dictionary/` フォルダにあります。

## English

A Japanese and English dictionary for `pytest`, `ruff`, `black`, `mypy`, `jupyter` and `pre-commit`. `python`, `pip` and `uv` are already in the bundled dictionary, so they are not included here.

`pre-commit install -f` replaces an existing git hook, so it shows a warning.
